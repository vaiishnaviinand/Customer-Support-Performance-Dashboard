# Customer Support Performance Dashboard

## Project Overview
This Business Analysis portfolio project analyses customer support ticket data to understand support performance, ticket trends, customer satisfaction, and resolution patterns.

The project uses Microsoft Excel for data cleaning, PostgreSQL and SQL for data analysis, and Power BI for interactive dashboard development.

## Objectives
- Analyse ticket volume and status distribution.
- Evaluate ticket closure rates across priorities and products.
- Explore customer satisfaction patterns.
- Analyse ticket trends across support channels and ticket types.
- Examine first response time patterns.
- Identify data quality issues and areas for further investigation.

## Tools Used
- Microsoft Excel
- PostgreSQL
- SQL
- Microsoft Power BI
- DAX

## Project Structure
- **BA Documentation:** BRD, User Stories, Acceptance Criteria, and Requirements Traceability Matrix (RTM).
- **Data:** Cleaned dataset in Excel and CSV formats.
- **Power BI:** Interactive dashboard file and exported report.
- **SQL:** SQL analysis queries and reference PDF.

## Key Findings
- The dataset contains 8,469 customer support tickets.
- 2,769 tickets were closed, representing a closure rate of 32.70%.
- Average customer satisfaction among closed tickets was 2.99 out of 5.
- Ticket volumes were relatively balanced across ticket statuses and support channels.
- Data quality analysis identified records with unusual timestamp relationships that require further investigation.

## Dashboard
The Power BI dashboard provides an interactive view of ticket performance, customer satisfaction, ticket trends, priority patterns, products, and support channels.
